# 💻 TechRent

Sistema web para gerenciamento de aluguel e controle de equipamentos de Tecnologia da Informação.

## 📌 Sobre o projeto

O TechRent é um projeto acadêmico desenvolvido com o objetivo de criar uma interface web para gerenciamento de equipamentos de TI alugados.

O sistema busca centralizar informações sobre equipamentos, contratos, solicitações, fornecedores, devoluções e pagamentos em uma única plataforma.

## 🎯 Objetivo

Desenvolver uma interface intuitiva e organizada para facilitar o controle e o acompanhamento dos equipamentos e processos relacionados à locação de equipamentos de TI.

## 🚀 Funcionalidades

- 🔐 Tela de login
- 📊 Dashboard
- 💻 Gerenciamento de equipamentos
- 📄 Controle de contratos
- 📋 Gerenciamento de solicitações
- 🏢 Cadastro de fornecedores
- 🔄 Controle de devoluções
- 💰 Controle de pagamentos
- 📈 Relatórios
